# Motor Speed Control & Monitoring
A semestral project for the Embedded Systems course at CTU. The goal is to control a motor and display its actual speed using an incremental encoder.

**Team members:**
*Mudra
*Pučok
*Tabačková

## Key Features:
* **Motor Control:** Speed regulated via an analog potentiometer (ADC to PWM).
* **Position Tracking:** Reading data from an Incremental Rotary Encoder (IRC).
* **Speed Derivation:** Calculating real-time speed by deriving the IRC position data over time.
* **Data Visualization:** Displaying the calculated speed on an LED text panel.
